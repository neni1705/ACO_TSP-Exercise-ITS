# TSPLIB datasets

The notebooks download `berlin52.tsp` and `eil76.tsp` from the public TSPLIB95 repository when first run. Files are cached here. The datasets are **not bundled** in this ZIP because remote retrieval was unavailable during packaging. Internet access is required for the first notebook run.

Official source: https://comopt.ifi.uni-heidelberg.de/software/TSPLIB95/

Alternative GitHub sources:
Berlin52: https://github.com/ProvideQ/tsp-problems
Eil76: https://github.com/mastqe/tsplib

Expected files: `berlin52.tsp`, `eil76.tsp`. You can also download them manually from the source and place them in this folder.
